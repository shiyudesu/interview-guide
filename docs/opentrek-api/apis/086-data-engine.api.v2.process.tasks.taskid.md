# 删除加工任务

- 文档序号：086
- 分类：平台功能类 / 数据中心 / 数据加工 / 删除加工任务
- 唯一编码：sfm.api.dataprocess.data-engine.api.v2.process.tasks.Taskid
- 请求方法：DELETE
- 调用地址：http://10.128.203.200:30226/gatectl/data-engine/api/v2/process/tasks/{taskId}
- 文档版本：1787280870609

## 接口概述

删除加工任务[DeleteProcessTask]

根据任务ID删除指定的加工任务。可以通过查看请求示例，点击 curl 命令示例右侧的调试按钮验证业务接口调用效果。

## 请求参数

### Header传参

| 字段 | 类型 | 必填 | 位置 | 描述 | 示例 |
| --- | --- | --- | --- | --- | --- |
| Authorization | String | 是 | header | APP_KEY | Bearer YOUR_APP_KEY |
| x-sfm-workspacecode | String | 是 | header | 目标工作空间 | your_workspace_code |
| Content-Type | String | 是 | header | Content-Type | application/json |

### Path传参

| 字段 | 类型 | 必填 | 位置 | 描述 | 示例 |
| --- | --- | --- | --- | --- | --- |
| taskId | Integer | 是 | url | 任务ID | 123 |

## 响应参数

| 字段 | 类型 | 必填 | 位置 | 描述 | 示例 |
| --- | --- | --- | --- | --- | --- |
| success | Boolean | 是 | body | 是否成功 | true |


## 请求示例

#### curl命令示例

```bash

-H 'Authorization: Bearer YOUR_APP_KEY' \
-H 'x-sfm-workspacecode: xxx'
```

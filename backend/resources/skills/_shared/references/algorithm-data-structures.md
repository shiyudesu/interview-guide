# 算法与数据结构（统一参考）

## 一、口述作答标准（文字/语音面试）
1. 先定义问题与状态：输入、输出、约束、目标。
2. 说明选型：为什么用该数据结构（而不是其他结构）。
3. 口述步骤：关键流程、转移关系、剪枝或维护不变式。
4. 复杂度：时间/空间复杂度 + 主瓶颈。
5. 边界与反例：空输入、重复值、极端规模、退化场景。

## 二、数组/链表
- 高频思路：双指针、滑动窗口、前缀和、原地算法。
- 典型追问：如何避免越界；是否能降空间；是否能单次扫描。

## 三、哈希/堆/栈/队列
- 哈希：去重、频次统计、映射索引、冲突与扩容代价。
- 堆：TopK、动态中位数、多路归并，关注 `O(n log k)` 优化。
- 栈：单调栈、括号匹配、表达式求值，不变式要说清。
- 队列：BFS、双端队列、滑窗最值，解释队头有效性。

## 四、树/图
- 树：前中后序、层序、递归/迭代取舍。
- 图：BFS/DFS、最短路、拓扑排序、并查集。
- 典型追问：有环/无环处理、访问标记时机、复杂度上界。

## 五、动态规划（DP）
- 核心：状态定义、转移方程、初始化、遍历顺序。
- 常见失误：状态遗漏、重复计算、滚动数组覆盖顺序错误。
- 追问方向：如何从 `O(n^2)` 优化到 `O(n log n)`（若可行）。

## 六、贪心/回溯
- 贪心：局部最优能否推导全局最优，需给交换论证或反例说明。
- 回溯：搜索树、剪枝条件、去重策略、最坏复杂度评估。

## 七、设计题（算法建模）
- 数据流、在线查询、延迟任务、限流计数等题型。
- 重点：结构选型、正确性、复杂度与工程可落地性。

## 八、场景问题
- 一个有序数组经过未知位置旋转，如何在 `O(log n)` 时间内查找目标值？重复元素会怎样改变判断？
- 接收持续到来的整数流，如何随时返回中位数？为什么需要两个堆，如何维护不变式？
- 设计一个支持 `O(1)` 查询和更新的 LRU 缓存，需要哪些数据结构，淘汰过程如何保持一致？
- 图中可能存在环，如何判断一组课程依赖是否能全部完成，并给出一种可行顺序？
- 一棵树非常深，递归遍历可能栈溢出，如何改成迭代实现并保持遍历顺序？
- 给定大量区间，如何合并重叠部分？排序后为什么只需要一次扫描？
- 动态规划中状态定义看似正确但结果重复计算，如何判断是状态不足还是转移顺序错误？
- 回溯枚举出现大量重复结果，如何从排序、同层去重和状态记忆三个层面优化？
- TopK 数据量远大于内存时，堆、分区、外部排序和近似算法分别适合什么情况？
- 滑动窗口最大值为什么可以用单调队列做到线性复杂度？队列中应保存值还是下标？
- 并查集如何判断动态连通性？路径压缩和按秩合并为什么能降低均摊复杂度？
- 一个算法平均很快但最坏情况不可接受，怎样构造退化输入并设计可验证的保护策略？
